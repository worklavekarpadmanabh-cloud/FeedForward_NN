CBOW is a Word2Vec architecture that predicts a target word from its surrounding context words. This practical uses a small, self-created sentence dataset, creates context–target pairs, trains a neural network, predicts a word, evaluates training predictions, and plots loss and accuracy.
Important: The dataset is intentionally small for learning. Results and predictions may vary because the same context can have more than one reasonable target word. The reported accuracy below is training accuracy, not accuracy on unseen test data.

║ IMPORTANT FORMULAS FOR VIVA                                          ║
╚══════════════════════════════════════════════════════════════════════╝

  FORMULA  • Average context vector: h = (1/C) × Σ E(wⱼ)
Averages the embedding vectors of the C context words.
  FORMULA  • Softmax probability: P(wᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
Converts output scores into probabilities across the vocabulary.
  FORMULA  • Predicted word: argmaxᵢ P(wᵢ)
Selects the word with the highest probability.
  FORMULA  • Sparse cross-entropy loss: L = −log(Pcorrect)
Penalizes the model when the correct target word receives a low probability.
  FORMULA  • Accuracy: Accuracy = (Correct predictions / Total predictions) × 100
Measures the percentage of predictions that match the target IDs.
  FORMULA  • General weight update: Wnew = Wold − α × (∂L/∂W)
Shows the basic gradient-descent update idea; Adam uses an adaptive update rule.

╔══════════════════════════════════════════════════════════════════════╗
║ IMPORTANT PRACTICAL NOTES                                            ║
╚══════════════════════════════════════════════════════════════════════╝

The training examples are context–target pairs. X contains context word IDs and y contains the target word ID.

For window_size = 1, each context has at most two positions: one word to the left and one to the right.
The Embedding dimension is 16 in this code. It is a chosen hyperparameter, not a fixed CBOW rule.

Padding index 0 is not a real vocabulary word. mask_zero=True tells the Embedding layer to mask it.

Training accuracy is calculated on the same examples used to train the model. It is not test accuracy and does not prove that the model generalizes to unseen sentences.
Because this is a very small synthetic dataset, predictions may vary and may not represent reliable general language understanding.

The final output can differ between runs because model weights are initialized and trained numerically.

║ SHORT VIVA EXPLANATION OF THE COMPLETE MODEL                         ║
╚══════════════════════════════════════════════════════════════════════╝

First, we tokenize the sentences and convert words into integer IDs. Next, we generate context–target pairs using a sliding window. The Embedding layer converts context word IDs into trainable vectors. GlobalAveragePooling1D averages those vectors into one context representation. The Dense layer with Softmax predicts probabilities for the vocabulary words. We train the model using Adam and sparse categorical cross-entropy, then select the highest-probability word using argmax. Finally, we calculate training accuracy and plot loss and accuracy.
