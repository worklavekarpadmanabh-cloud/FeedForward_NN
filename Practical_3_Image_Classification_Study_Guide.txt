1.  model = Sequential([…])

    WHAT: Creates a Keras Sequential model and stores it in the variable

    WHAT: Defines the shape of one input sample.

    WHAT: Creates a fully connected hidden layer containing 128 neurons.

    FORMULA: exp(z_i) softmax(z_i) = —————– sum_j exp(z_j)

model.compile()

WHAT: Configures the model before training.

    WHAT: Selects Adam (Adaptive Moment Estimation) as the optimizer.

POOLING FORMULA — FROM YOUR SUPPLIED IMAGE
================================================================================

IMPORTANT CONTEXT

Pooling is commonly used in Convolutional Neural Networks (CNNs). It
reduces the spatial dimensions (height and width) of feature maps.

Your current Dense MNIST model does not contain a pooling layer. This
formula is included as a separate CNN concept for study.

FORMULA

                    N - F + 2P
              O = ------------- + 1
                         S

Where: O = Output dimension N = Input dimension (height or width) F =
Filter or pool-window size P = Padding S = Stride

WHAT EACH TERM MEANS

N — Input size: Height or width of the input feature map.

F — Filter / pool size: Height or width of the pooling window.

P — Padding: Number of padding cells added to each side.

S — Stride: Number of positions the window moves at each step.

O — Output size: Resulting height or width after the operation.

WORKED EXAMPLE — 2 × 2 POOLING ON A 28 × 28 INPUT

Suppose: N = 28 F = 2 P = 0 S = 2

Substitute into the formula:

                  28 - 2 + 2(0)
            O = ---------------- + 1
                         2

                  26
            O = ------ + 1
                   2

            O = 13 + 1

            O = 14

Therefore: Input size = 28 × 28 Output size = 14 × 14

The height becomes 14 and the width becomes 14.

WHY DOES POOLING REDUCE SIZE?

A 2 × 2 pooling window with stride 2 moves two positions at a time. It
summarizes each 2 × 2 region into one value, reducing the spatial
dimensions.

MAX POOLING EXAMPLE

Consider this 2 × 2 region:

       1   3
       2   4

Max pooling selects the largest value:

       max(1, 3, 2, 4) = 4

AVERAGE POOLING EXAMPLE

For the same region:

       1   3
       2   4

Average pooling calculates:

       (1 + 3 + 2 + 4) / 4 = 2.5

DIFFERENCE

Max Pooling: Selects the maximum value from each pooling region.

Average Pooling: Calculates the average value of each pooling region.

NOTE ABOUT THE FORMULA: The formula is applied separately to height and
width. For a square input and square pooling window, the same values can
be used for both. The dimensions should produce a valid output size for
the chosen padding and stride.

assigning an image to one of the predefined classes.

Q2. What is MNIST? A. MNIST is a handwritten-digit dataset containing

Q3. Why normalize pixel values? A. To scale them from 0–255 to 0–1,
helping neural-network training.

Q4. Why flatten the images? A. The Dense network expects a
one-dimensional feature vector. A 28 × 28 image is converted into 784
features.

Q5. What is Sequential? A. A Keras model in which layers are arranged
one after another.

Q6. What is a Dense layer? A. A fully connected layer in which each
neuron connects to every output from the previous layer.

that provides units to learn patterns from the input features.

Q8. Why use ReLU? A. It introduces non-linearity in the hidden layer.

Q9. Why are there 10 output neurons? A. There are ten digit classes,
from 0 to 9.

Q10. Why use Softmax? A. It converts output scores into probabilities
across the ten classes.

Q11. What is Adam? A. Adaptive Moment Estimation, an optimizer that
adapts parameter updates using estimates of gradients and squared
gradients.

Q12. What is sparse categorical crossentropy? A. A loss function for
multi-class classification when target labels are integer class IDs.

Q13. What is accuracy? A. The fraction of predictions that are correct.

Q14. What is an epoch? A. One complete pass through the training portion
of the dataset.

Q15. What is batch size? A. The number of samples processed in one
mini-batch.

Q16. What is validation_split=0.1? A. It reserves 10% of the supplied
training data for validation.

Q17. What is model.evaluate()? A. It calculates the model’s loss and
configured metrics on supplied data.

Q18. What is a confusion matrix? A. A table comparing actual classes
with predicted classes.

Q19. What is precision? A. Of all samples predicted as a class, the
fraction that actually belongs to that class.

Q20. What is recall? A. Of all actual samples in a class, the fraction
correctly identified.

Q21. What is F1-score? A. The harmonic mean of precision and recall.

Q22. What is support? A. The number of actual samples belonging to a
class.

Q23. What is pooling? A. A CNN operation that reduces the spatial
dimensions of feature maps.

Q24. What is max pooling? A. It selects the maximum value from each
pooling window.

Q25. What is average pooling? A. It calculates the average value in each
pooling window.

Q26. What does np.argmax() do? A. It returns the index of the maximum
value. Here it selects the predicted digit with the highest Softmax
probability.

Q27. What is overfitting? A. When a model fits training data very
closely but performs less well on unseen data.

Q28. Does this practical’s model use pooling? A. No. This implementation
uses Dense layers only. The pooling formula is a separate CNN concept
and is not used in this model.

Loss graph : Lower is generally better. Accuracy graph : Higher is

CLASSIFICATION REPORT MEMORY TIP

Precision = Correct among predicted positives. Recall = Correct among
actual positives. F1-score = Balance of precision and recall. Support =
Number of actual samples.

POOLING MEMORY TIP

Max pooling = Select maximum. Average pooling = Calculate average.
Output formula = (N - F + 2P) / S + 1.
